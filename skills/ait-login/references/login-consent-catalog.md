# 토스 로그인 — 약관·동의문 드롭다운 카탈로그 (콘솔 실측)

콘솔 [+ 추가하기] > 동의문에서 고르는 값이다. **공식 문서에는 이 선택지 목록이 없다.**

## 처리 목적 (4종)

```
수집·이용
제3자 제공
제3자 수신
국외이전
```

## 동의문 유형 (17종)

| 코드 | 화면 표기 |
|---|---|
| `privacyPolicyAgreed` | 개인정보 처리방침 동의 |
| `terms_policy` | 파트너사 이용약관 |
| `privacy_notice` | 파트너사 개인정보 수집이용동의 |
| `user_age_check` | 만 14세 이상 확인 |
| `customer_benefit` | 고객 혜택 제공을 위한 정보 수집 및 이용 동의 |
| `marketing_promotion` | 혜택정보·광고 수신 동의 |
| `personal_information_required` | 개인정보 수집 및 이용 동의 |
| `marketing_agree` | 개인정보 마케팅 활용 동의 |
| `marketing_receive_agree` | 광고성 정보 수신 동의 |
| `finance_terms_policy` | 전자금융거래 이용약관 |
| `personal_information_provision` | 개인정보 제3자제공동의 |
| `personal_information_provision_save` | 포인트 적립/사용을 위한 개인정보 제3자 제공 동의 |
| `personal_information_provision_check` | 포인트 자동조회를 위한 개인정보 제3자 제공 동의 |
| `receive_sms` | 이벤트 및 쇼핑혜택 SMS수신동의 |
| `receive_email` | 이벤트 및 쇼핑혜택 이메일수신동의 |
| `location_based_agree` | 위치기반 서비스 이용약관 |

(목록 중 1건은 스크롤에 가려 확인하지 못했다.)

## 알려진 불일치 — 국외 이전 전용 유형이 없다

처리 목적에는 `국외이전`이 있지만 **동의문 유형에는 대응 항목이 없다.**

**우회**: 국외 이전 동의문은 유형을 `privacy_notice`(파트너사 개인정보 수집이용동의)로 고르고, **처리 목적을 `국외이전`으로 설정**해 구분한다. 제목에 "개인정보 국외 이전 동의"를 명시한다.

## 미니앱 기본 조합 (외부 LLM을 호출하는 일반적인 경우)

| 문서 | 조건 | 처리 목적 | 동의문 유형 | 만 14세 미만 |
|---|---|---|---|---|
| 서비스 이용약관 | 필수 | — (기본 슬롯 [등록], URL만 입력) | — | — |
| 개인정보 수집·이용 동의 | 필수 | 수집·이용 | `personal_information_required` | 사용 안 함 |
| 개인정보 국외 이전 동의 | 필수 | **국외이전** | `privacy_notice` | 사용 안 함 |
| 마케팅 정보 수신 동의 | 선택 | 수집·이용 | `marketing_receive_agree` | 사용 안 함 |

- **만 14세 미만 사용 여부의 기본값은 `사용`이다.** 앱인토스는 만 19세 이상에게만 제공되므로 `사용 안 함`으로 바꾼다.
- 야간(21:00~08:00) 발송을 할 계획이면 **야간 혜택 수신 동의(선택)**를 추가로 등록한다.
