# 약관·개인정보 처리방침 초안 + 정적 서빙

토스 로그인 등록에 필요한 약관 URL을 **서버 정적 파일 라우트**로 확보한다. 초안을 생성해 서버가 HTML로 리턴하고, 그 URL을 콘솔에 등록한다.

> **법적 면책**: 아래는 **초안 골격**이다. 책임·환불·분쟁·관할 등은 운영자가 법적 검토 후 확정한다.

## 1. 생성물

- `docs/legal/terms.html` — 서비스 이용약관
- `docs/legal/privacy.html` — 개인정보 처리방침 (수집 항목은 동의 항목과 일치시킴)

수집 항목 자동 반영: OAuth 동의 항목으로 켠 scope(예: 이름·이메일·휴대폰)를 개인정보 처리방침 "① 수집하는 개인정보 항목"에 그대로 기재한다.

## 2. 서버 정적 서빙 (back-developer 담당)

API 서버가 있으면 정적 라우트를 추가한다. 예(Express):

```js
import path from 'node:path';
import express from 'express';
const app = express();

// 약관 정적 서빙 — 공개 GET, 인증 불필요
app.use('/legal', express.static(path.join(process.cwd(), 'docs/legal'), {
  setHeaders: (res) => res.type('text/html; charset=utf-8'),
}));
// → https://{서버도메인}/legal/terms.html , /legal/privacy.html
```

서버가 없는 순수 프론트 미니앱이면 **미니앱 라우트**(`/terms`·`/privacy`)로 약관 페이지를 띄워 그 URL을 쓰거나, GitHub Pages 등 외부 공개 URL을 쓴다.

## 3. 콘솔 등록

확보한 URL을 토스 로그인 "약관/동의문"에 입력. SUBMIT.md "토스 로그인 설정"에 URL 기록.

## 4. 서비스 이용약관 골격 (terms.html 본문)

```
제1조 (목적) 본 약관은 「{앱명}」(이하 "서비스")의 이용 조건·절차, 이용자와 운영자의 권리·의무를 정합니다.
제2조 (정의) 1. "이용자"란 본 서비스에 접속하여 본 약관에 따라 서비스를 이용하는 자를 말합니다. …
제3조 (약관의 효력 및 변경) 운영자는 관련 법령을 위반하지 않는 범위에서 약관을 변경할 수 있으며, 변경 시 적용일자·사유를 명시하여 공지합니다.
제4조 (서비스의 제공) 운영자는 {핵심 기능 요약}을 제공합니다. 운영상·기술상 필요 시 서비스의 전부 또는 일부를 변경할 수 있습니다.
제5조 (서비스 이용시간) 연중무휴 24시간을 원칙으로 하되, 점검 등 사유로 중단될 수 있습니다.
제6조 (이용자의 의무) 이용자는 관계 법령, 본 약관, 운영자 공지사항을 준수해야 하며 타인의 권리를 침해해서는 안 됩니다.
제7조 (책임의 한계) 천재지변·불가항력, 이용자 귀책으로 인한 손해에 대해 운영자는 책임을 지지 않습니다. [운영자 법적 검토 필수]
제8조 (분쟁 해결 및 관할) 본 약관은 대한민국 법령에 따르며, 분쟁은 [관할 법원]을 제1심 관할로 합니다. [확정 필요]
부칙: 본 약관은 {시행일}부터 시행합니다.
```

## 5. 개인정보 처리방침 골격 (privacy.html 본문)

```
① 수집하는 개인정보 항목: {동의 항목으로 켠 scope를 그대로 — 예: 이름, 이메일 주소, 휴대전화번호}
   ※ 이름(필수 강제)만 받는 앱: "토스 사용자 식별값(userKey), 이름" 수집. 저장하지 않고 식별만 하면 그 사실을 기재.
② 수집·이용 목적: {각 항목의 사용 목적 — 예: 이름(개인화 표시), 이메일(알림)}
③ 보유·이용 기간: 회원 탈퇴 또는 토스 로그인 연결 끊기 시 지체 없이 파기. (법령상 보존 의무 시 해당 기간)
④ 제3자 제공: 제공하지 않습니다. (있으면 대상·항목·목적 명시)
⑤ 처리 위탁: {호스팅·인프라 등 수탁자 — 없으면 "없음"}
⑥ 이용자 권리: 열람·정정·삭제·처리정지 요구 가능. 연결 끊기 시 관련 정보 파기.
⑦ 파기 절차·방법: 목적 달성 시 지체 없이 파기, 전자적 파일은 복구 불가하게 삭제.
⑧ 개인정보 보호책임자: {이름/이메일} (콘솔 고객센터 정보와 일치)
시행일: {시행일}
```

> 데이터를 **기기에만 저장하고 서버로 보내지 않는** 앱은 ①에 "userKey 외 개인정보 미수집, 입력 데이터는 이용자 기기에만 저장"으로 정확히 기재한다.
