## 9. 🙋 사용자가 해야 할 것
MANUAL 전환된 콘솔 write 작업 체크리스트. 각 항목은 `- [ ] {무엇을} — 콘솔 경로: {메뉴 경로} — 왜: {이유}` 형식으로 기재.
해당 작업(앱 정보 입력, 검토 요청, 출시, 검토 취소, 테스트 발송, 스마트발송 캠페인, 프로모션 등록·비즈월렛 충전 중 해당하는 것)만 기재하고, 잔여 작업이 없으면 '없음'으로 명기.
이 섹션은 항상 보고서의 마지막 섹션이어야 한다.

- [ ] 앱 정보 입력 — 콘솔 경로: 앱 관리 > 앱 정보 — 왜: 부제·상세설명·카테고리·키워드를 콘솔에 직접 입력해야 함
- [ ] 검토 요청 — 콘솔 경로: 앱 관리 > 검토 요청 — 왜: 빌드 업로드 후 검토를 수동으로 트리거해야 함
- [ ] 출시 — 콘솔 경로: 앱 관리 > 출시 관리 — 왜: 검토 승인 후 최종 출시는 수동 확인 필요
- [ ] (기능성 스마트발송 사용 시) 알림동의문 이름 입력 — 콘솔 경로: 워크스페이스 → 미니앱 → 스마트 발송 → 알림동의문 — 왜: 기능성 메시지 발송 전 동의문 이름을 콘솔에 직접 등록해야 함
- [ ] (기능성 스마트발송 사용 시) 알림 발송 시점 입력 — 콘솔 경로: 워크스페이스 → 미니앱 → 스마트 발송 → 캠페인 생성 — 왜: 기능성 메시지는 발송 시점(일회성/정기)을 사용자가 직접 지정해야 함
