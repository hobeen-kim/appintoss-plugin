# 푸시 알림 마케팅 소재 가이드

## CTR 높이는 공식

토스 푸시 문구 = **20자 이내** + **행동 유도** + **구체적 가치**

### 좋은 예
- "오늘의 운세 확인하세요" (X) → "3월 18일 물병자리 대박운!" (O)
- "새 기능이 추가됐어요" (X) → "커피 쿠폰 1장, 지금 받으세요" (O)
- "앱을 사용해보세요" (X) → "5초면 끝! 내 세금 환급액 확인" (O)

### 문구 작성 프레임워크

```
[수치/기한] + [대상이 얻는 것] + [행동 유도]

예시:
"오늘까지! 무료 운세 3회 제공"
"30초 안에 내 적금 이자 계산"
"이번 주 인기 퀴즈 TOP 5"
```

## 세그먼트 타겟팅

토스는 실제 결제 데이터 기반 100+개 카테고리로 무료 타겟팅 가능.

### 주요 세그먼트 활용

| 세그먼트 | 타겟팅 키워드 예시 | 적합한 앱 |
|---------|-----------------|---------|
| 커피 소비자 | "커피 자주 마시는" | 카페 추천, 쿠폰 |
| 1인가구 | "혼자 사는" | 생활 팁, 요리 |
| 뷰티/패션 | "뷰티 트렌드 관심" | 뷰티 퀴즈, 추천 |
| 투자 관심 | "금융 정보 관심" | 계산기, 세금 |
| 게임 이용자 | "게임 자주 하는" | 미니게임, 퀴즈 |

### 토스 유저 특성
- **핵심 활성층: 40대 이상** — 20대 CTR 매우 낮음
- 10대는 앱인토스 사용 불가
- 4%가 성사시키는 마법: CTR 4~5% 이상이면 토스가 계속 발송

## A/B 테스트 템플릿

### 대조군 설정
- 변수 하나만 변경 (문구만, 또는 시간만)
- 최소 1일 이상 실행

### 테스트 변수

| 변수 | A안 | B안 |
|------|-----|-----|
| 문구 스타일 | 정보형 "오늘의 상식" | 호기심형 "이거 몰랐죠?" |
| 발송 시간 | 오전 8시 | 오후 12시 |
| 이모지 | 없음 | 있음 |
| 수치 포함 | 없음 | "3분이면 끝" |

## 콘솔 마케팅 설정

### 필수 작성 항목
1. **부제** (20자 이내) — 검색/목록에서 앱 이름 아래 표시
2. **상세 설명** — 앱 상세 페이지
3. **검색 키워드** — 트렌드 유입 키워드

### 스마트발송 설정
- 앱인토스 콘솔 → 마케팅 → 스마트발송
- 타겟 세그먼트 설정
- 발송 시간 설정 (최적: 출퇴근 시간대)
- CTR 20%+ 달성 시 토스가 자동으로 발송량 증가
