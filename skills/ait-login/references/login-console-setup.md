# 토스 로그인 — 콘솔 설정 절차

미니앱은 **토스 로그인 외의 로그인 수단을 쓸 수 없다**. 이 설정이 끝나야 앱이 첫 화면을 넘어간다. 기능성 푸시·알림, 프로모션, 토스페이도 토스 로그인 연동이 선행되어야 한다.

공식 문서(`guide/authentication/intro`)는 "1. 약관 동의하기 / 2. 설정하기" 두 줄뿐이고, 콘솔 실제 입력 항목과 드롭다운 선택지는 문서화돼 있지 않다. 아래는 **콘솔 실측 기준**이다.

---

## 0단계: 대표관리자 게이트 — 개발 착수 전에 확인한다

**토스 로그인 약관 동의는 대표관리자 계정에서만 할 수 있다.** 동의 전에는 설정 화면 전체가 잠기고 `"대표관리자가 약관에 동의해야 사용할 수 있어요"` 배너만 뜬다.

- 워크스페이스를 만든 사람이 자동으로 대표관리자가 된다. **발주처가 워크스페이스를 만들었다면 협조가 반드시 필요하다.**
- 권한 등급은 **관리자**(워크스페이스 전체 관리 + 정산 정보 조회)와 **구성원**(권한 받은 앱 조회·관리) 둘뿐이다. 동의 이후 설정 항목을 누가 입력할 수 있는지는 공식 문서에 정의돼 있지 않다.
- 대표관리자 위임: 워크스페이스 > 멤버 탭 > [권한 위임]. **현재 대표관리자가 직접 눌러야 한다.** 대표관리자는 관리자 중에서만 지정할 수 있고 구성원은 불가하다. 사업자 정보가 등록돼 있으면 같은 회사 소속 확인 절차가 붙는다(대표자는 기존 서류로 확인, 대리인은 인감증명서·위임장·신분증 사본 필요).

**에이전트 행동**: 콘솔 계정이 대표관리자가 아니면 즉시 "발주처 협조 필요" 상태로 전환하고, 요청 문안과 위임 절차를 산출한다. 이 게이트를 개발 착수 전에 확인해야 막판에 멈추지 않는다.

---

## 1단계: 동의 항목(스코프) 결정

기능에서 실제로 쓰는 항목만 켠다.

| 항목 | 코드 | 비고 |
|---|---|---|
| 이름 | `USER_NAME` | **필수 동의 고정** — 해제 불가(선택 동의·사용 안 함이 비활성) |
| 이메일 | `USER_EMAIL` | 토스 가입 시 필수가 아니라 **`null`이 올 수 있다** — 서버가 허용해야 한다 |
| 성별 | `USER_GENDER` | |
| 생일 | `USER_BIRTHDAY` | |
| 국적 | `USER_NATIONALITY` | |
| 전화번호 | `USER_PHONE` | |
| CI | `USER_CI` | 본인인증 기관 발급 불변 식별값. 개인식별정보(PII)이므로 **암호화 저장 필수**, 최소 수집 원칙 |

**이름·이메일·성별 외 항목을 하나라도 켜면 연결 끊기 콜백 정보 입력이 필수가 된다.** 콜백 URL 구현까지 함께 설계한다.

**연동할 서비스**: 이미 토스 로그인을 쓰는 서비스가 있으면 목록에 노출된다. 선택하면 그 서비스의 `userKey`가 동일하게 매핑된다. `userKey`는 앱 단위로 고유하므로, 같은 사용자라도 앱이 다르면 값이 달라진다.

## 2단계: 약관/동의문 등록

**토스 로그인 필수 약관(서비스 약관, 개인정보 제3자 제공 동의)은 자동 포함**된다. 파트너사가 직접 등록하는 것은 아래다.

등록 경로가 두 가지이고 **화면이 다르다.**

### (a) 기본 슬롯의 [등록] 버튼
"서비스 이용약관"(필수)·"마케팅 정보 수신 동의"(선택)는 자리가 이미 있다. [등록]을 누르면 제목·유형·조건이 미리 채워진 채 비활성이고 **URL 한 칸만 입력**한다.

### (b) [+ 추가하기]
그 밖의 문서는 여기서 만든다. 먼저 유형을 묻는다.
- **약관** — "서비스 전체에 적용되는 규칙과 조건"
- **동의문** — "특정 기능 이용 시 필요한 개별 동의"

두 경로의 입력 항목이 다르다.

| 약관 추가하기 | 동의문 추가하기 |
|---|---|
| 약관 제목 | 동의문 제목 |
| 약관 URL | 동의문 URL |
| 약관 유형 | **처리 목적** |
| 약관 조건 (필수/선택) | 동의문 유형 |
| — | 동의문 조건 (필수/선택) |
| — | **만 14세 미만 사용 여부** (사용 / 사용 안 함 / 미정) |

드롭다운 선택지 전체는 `login-consent-catalog.md` 참조.

### 만 14세 미만 사용 여부 — 기본값이 위험한 쪽이다
기본값이 **`사용`**이다. 토스 계정은 만 14세 이상만 만들 수 있고 앱인토스는 만 19세 이상에게만 제공되므로 미니앱에는 해당 이용자가 없다. **`사용 안 함`으로 바꾼다.** `사용`으로 두면 법정대리인 동의 절차를 갖춰야 한다.

### 외부 LLM을 쓰면 국외 이전 동의가 필수다
공홈: "해외 클라우드 리전이나 해외 사업자의 서버에 토스 로그인으로 받은 개인정보를 저장하거나 이전한다면, **개인정보 국외 이전 동의문을 필수로 등록**해 주세요."

Gemini·OpenAI·Anthropic 등 **해외 사업자 API로 이용자 입력을 보내는 순간 해당된다.** 이 플러그인이 만드는 미니앱은 대부분 외부 LLM을 호출하므로 사실상 항상 필수다.

동의문 필수 기재(개인정보 보호법 §28-8): 이전받는 자 / 이전되는 국가 / 이전받는 자의 연락처 / 이전 항목 / 이전 시점과 방법 / 이용 목적 / 보유·이용 기간.

> 공홈이 안내하는 등록 가능 약관: 서비스 이용약관, 개인정보 수집·이용 동의, 마케팅 정보 수신 동의(선택), **야간 혜택 수신 동의(선택, 21:00~08:00 발송 여부 명시)**, 개인정보 국외 이전 동의(해당 시).

## 3단계: 약관 URL 게시

약관·동의문은 **공개 HTTPS URL**이어야 한다. 미니앱 번들 내부 경로는 쓸 수 없고, **인증을 걸면 안 된다**(로그인 전에 열려야 한다).

도메인을 따로 사지 않아도 된다 — API 서버에 정적 HTML 라우트(`/legal/terms`, `/legal/privacy`, `/legal/transfer-abroad`)를 두고 앞단 CDN이 HTTPS를 종단하면 그 주소를 그대로 등록한다.

검수 항목이기도 하다: "설정한 토스 로그인 약관 화면 URL이 정상적으로 노출돼요."

---

## 4단계: 연결 끊기 콜백

| 항목 | 설명 |
|---|---|
| 콜백 URL | 사용자가 로그인 연결을 해제했을 때 호출할 URL |
| HTTP 메서드 | `GET` 또는 `POST` |
| Basic Auth 헤더 | base64로 인코딩돼 전달된다. 디코딩해 콘솔 입력값과 일치하는지 검증한다 |

**연결 끊기 이벤트 경로는 3가지**이고 `referrer` 값으로 구분한다.

| referrer | 발생 시점 |
|---|---|
| `UNLINK` | 사용자가 앱에서 직접 연결을 끊음 (토스 앱 > 설정 > 인증 및 보안 > 토스로 로그인한 서비스 > 연결 끊기) → **로그아웃 처리** |
| `WITHDRAWAL_TERMS` | 로그인 서비스 약관 철회 (설정 > 법적 정보 및 기타 > 약관 및 개인정보 처리 동의 > "토스 로그인" > 동의 철회하기) |
| `WITHDRAWAL_TOSS` | 토스 회원 탈퇴 |

연결이 끊기면 토스는 동의 약관과 로그인 정보를 모두 삭제한다. 서비스도 세션·토큰을 정리하고 사용자 데이터를 남기지 않아야 한다(검수 항목). "토스 연결이 해제되어 다시 로그인해야 해요" 같은 재로그인 안내를 제공하는 것이 권장된다.

---

## 5단계: 복호화 키 수령

토스 로그인 정보 등록이 끝나면 콘솔의 **'이메일로 복호화 키 받기'** 버튼으로 키를 받는다. 응답 복호화(AES-256-GCM, 암호문 앞에 IV 포함, AAD 필요)에 쓴다.

- 절대 외부 노출 금지. 시크릿 매니저에 보관하고 서버에서만 사용한다.
- 재발급이 필요하면 채널톡으로 문의한다.

---

## 6단계: 등록값 표 산출

대표관리자가 콘솔에 그대로 옮겨 적을 수 있는 형태로 출력한다.

```
[동의 항목]
이름        : 필수 (고정)
이메일      : 선택 / 사용 안 함    ← null 허용 처리 여부 확인
...

[약관·동의문]
1) 서비스 이용약관        | 필수 | https://{host}/legal/terms
2) 개인정보 수집·이용 동의 | 필수 | https://{host}/legal/privacy   | 처리 목적: 수집·이용 | 유형: personal_information_required | 만 14세 미만: 사용 안 함
3) 개인정보 국외 이전 동의 | 필수 | https://{host}/legal/transfer  | 처리 목적: 국외이전   | 유형: privacy_notice               | 만 14세 미만: 사용 안 함
4) 마케팅 정보 수신 동의   | 선택 | https://{host}/legal/marketing | 처리 목적: 수집·이용 | 유형: marketing_receive_agree      | 만 14세 미만: 사용 안 함

[연결 끊기 콜백]
URL: https://{host}/auth/unlink | 메서드: POST | Basic Auth: {id}:{pw}
```

## 자체 웹·앱에도 토스 로그인을 붙이려면

원래 토스 인증 부서와 별도 계약이 필요하지만, **앱인토스에서 토스 로그인을 쓰는 파트너사는 별도 계약 없이 쓸 수 있다.** 콘솔에서 토스 로그인을 먼저 신청한 뒤, 웹/앱 여부·회원 식별 키·필요 개인정보 항목·약관 목록·`redirect_uri`·연동 예정 앱 버전·연결 끊기 API 사용 여부·네트워크 정보를 정리해 `cert.support@toss.im`으로 Client ID 발급을 요청한다.
