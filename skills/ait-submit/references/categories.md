# 앱인토스 미니앱 카테고리 (콘솔 실데이터, 2026-06-09)

콘솔 API 응답 기준 실제 카테고리 트리. **`isSelectable: true`인 항목만 파트너 미니앱이 선택 가능**하다. 추천 시 selectable=true만 제안하라.

## 선택 규칙
- **금융 그룹(전체 `isSelectable: false`)** — 토스 자체 기능 카테고리. **파트너 미니앱은 선택 불가.** 추천하지 마라.
- **게임 그룹** — 그룹·전 항목 selectable. 게임 앱이면 장르 1개 선택.
- **생활 그룹** — 대부분 selectable. 단 `틴즈`·`민원`·`결혼`은 `isSelectable: false`(선택 불가). 하위 분류가 있는 항목은 **소분류까지 선택**.

## 게임 (장르, 모두 선택 가능)
액션 · RPG · 전략 · 어드벤처 · 퍼즐 · 시뮬레이션 · 레이싱 · 퀴즈 · 카드 · 보드 · 클래식 · 음악 · 스포츠 · 인디

- **음식 · 음료**: 음식 · 음료
- **교육**: 교육
- **건강**: 건강 관리 · 심리 · 운동 · 의료 · 영양·식단 · 기타
- **교통**: 자동차 · 렌터카 · 항공 · 기타
- **공공·행정**: 공공·행정
- **소셜**: 소셜
- **편의**: 도구 · 구독·렌탈 · 기타
- **쇼핑**: 쇼핑
- **AI**: AI
- **비즈니스**: 구인구직 · 직장 · 사장님 · 기타
- **콘텐츠**: 공연·이벤트 · 웹툰 · 음악·오디오 · 영상 · 운세 · 테스트 · 기타

### 선택 불가 (참고, 추천 금지)
- 생활: 틴즈 · 민원 · 결혼 (isSelectable=false)
- 금융 그룹 전체: 계좌개설 · 송금 · ATM출금 · 카드 · 토스페이 · 대출 받기 · 신용 점수 · 투자·연금 · 부동산 · 보험 · 여행 · 연금 준비 · 세금 · 모바일·인터넷 · 내 자산 · 소비 · 자동차 · 토스프라임 멤버십 · 토스뱅크 · 자녀 · 결제

## 추천 방법
PLAN.md 주제·타겟 기반으로 위 selectable 트리에서 **대분류+소분류 추천 1개 + 대안 1개**를 제안한다. 예: 가계부/봉투 → 일상·기타 또는 정보·기타 / 운세 테스트 → 콘텐츠·운세 또는 콘텐츠·테스트 / 음식 추천 → 음식·음료.
