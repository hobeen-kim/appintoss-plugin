# 앱인토스 미니앱 카테고리 (콘솔 실데이터, 2026-06-09; 포인트 카테고리 공지 반영 2026-06-11)

콘솔 API 응답 기준 실제 카테고리 트리. **`isSelectable: true`인 항목만 파트너 미니앱이 선택 가능**하다. 추천 시 selectable=true만 제안하라.

## 콘솔 입력은 3단계다 — 이 문서의 표기 대응 (중요)

콘솔 앱 정보의 카테고리 입력란은 **대/중/소 3단 셀렉터**다. 이 문서의 헤딩·리스트가 각 단계에 이렇게 대응한다.

| 콘솔 셀렉터 | 이 문서의 표기 | 예 |
|---|---|---|
| **대분류** (1단) | `##` 그룹 헤딩 — `게임` · `생활` · `금융`(선택 불가) · `포인트` | 생활 |
| **중분류** (2단) | 리스트의 **굵은 항목** | 일상 |
| **소분류** (3단) | 굵은 항목 뒤 ` · `로 나열된 값 | 기타 |

→ 콘솔 입력값은 **`생활 > 일상 > 기타`** 같은 3단 경로다. "생활 > 일상" 2단으로 준비하면 중분류 칸까지만 채워지고 진행이 막힌다.
**APP-SPEC.md·산출 문서에는 반드시 3단 전체 경로로 적는다.**

- 굵은 항목과 소분류 이름이 같은 경우(`**교육**: 교육`, `**쇼핑**: 쇼핑`)는 `생활 > 교육 > 교육`처럼 중·소분류가 동일한 값으로 반복된다.
- **선택은 한 경로만 한다.** 아래 "추천 방법"의 1순위/대안은 *제안 후보*이지 복수 선택이 아니다.
- 자동화 스크립트 `ait-console/scripts/cat-capture.cjs`도 이 3단(대→중→소) 순서로 클릭한다.

## 선택 규칙
- **금융 그룹(전체 `isSelectable: false`)** — 토스 자체 기능 카테고리. **파트너 미니앱은 선택 불가.** 추천하지 마라.
- **게임 그룹** — 그룹·전 항목 selectable. 게임 앱이면 장르 1개 선택.
- **생활 그룹** — 대부분 selectable. 단 `틴즈`·`민원`·`결혼`은 `isSelectable: false`(선택 불가). 하위 분류가 있는 항목은 **소분류까지 선택**.

## 추천 방법
PLAN.md 주제·타겟 기반으로 위 selectable 트리에서 **3단 전체 경로 추천 1개 + 대안 1개**를 제안한다(둘 중 하나만 콘솔에 입력한다). 예: 가계부/봉투 → `생활 > 일상 > 기타` 또는 `생활 > 정보 > 기타` / 운세 테스트 → `생활 > 콘텐츠 > 운세` 또는 `생활 > 콘텐츠 > 테스트` / 음식 추천 → `생활 > 음식·음료 > 음식` / **앱테크·리워드 적립형 앱 → 포인트 카테고리**.
