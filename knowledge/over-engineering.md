# Over Engineering 방지

## 원칙

CLAUDE.md에 6줄 추가하면 42줄짜리 ButtonFactory가 3줄짜리 버튼이 된다.

## NEVER

1. **요청하지 않은 추상화 금지** — 한 번만 쓰이는 코드에 헬퍼/유틸리티/팩토리 만들지 않는다
2. **미래 대비 설계 금지** — "나중에 필요할 수도" 는 지금 필요 없다는 뜻
3. **불필요한 에러 핸들링 금지** — 내부 코드와 프레임워크를 신뢰하라. 시스템 경계(사용자 입력, 외부 API)에서만 검증
4. **과도한 타입/주석 금지** — 변경하지 않은 코드에 docstring, 타입 어노테이션, 주석 추가 금지

## ALWAYS

1. **최소 복잡도** — 현재 작업에 필요한 최소한의 코드만 작성
2. **3줄 규칙** — 비슷한 코드 3줄이 조기 추상화보다 낫다
3. **삭제 우선** — 사용하지 않는 코드는 주석 처리 대신 완전 삭제

## 예시

```
# BAD: Over-Engineered
class ButtonFactory:
    def create_button(self, type, config):
        ...  # 42줄

# GOOD: 단순
<Button variant="primary">확인</Button>
```

## "첫 단추의 법칙"

AI 코딩 실패의 대부분은 출력이 아니라 입력에서 발생한다.
스펙이 모호하면 코드도 모호하다.
