## 앱 내 기능

> 검색 결과·미니홈에서 특정 기능으로 바로 진입(홈을 거치지 않음)하게 하는 콘솔 등록 항목. 공식 규격(2026-06-10 공홈 확인):
> - **한국어 기능 이름**: 최대 10자, 허용 특수문자 `:` `.`만, 이모지 불가, "~하기" 또는 명사형
> - **영어 기능 이름**: 최대 15자, 허용 특수문자 `:` `.`만, 이모지 불가, 첫 글자만 대문자
> - **이동 URL**: `intoss://{appName}/경로`, 홈은 `/`, 쿼리 파라미터 가능
> - 최소 1개 필수(비게임), URL 미접속 시 반려, 검토는 영업일 1~2일 소요
> - 출처: https://developers-apps-in-toss.toss.im/development/test/function.html
