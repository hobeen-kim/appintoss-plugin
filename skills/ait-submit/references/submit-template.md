## 검수 안내

- 검수 4단계: 운영 / 디자인 / 기능 / 보안 — 영업일 기준 2~3일 소요
- 재검수는 수 시간 내 완료
- **앱 정보 검수와 코드 검수는 별개 단계**
- 자동 검수 오탐 시 채널톡으로 수동 승인 요청
