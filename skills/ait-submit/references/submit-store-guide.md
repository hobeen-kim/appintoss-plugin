# 스토어 노출 정보 작성 가이드

콘솔 등록 필드별 작성 규칙. 출처: 공홈 콘솔 등록 가이드(developers-apps-in-toss.toss.im/prepare/console-workspace.html)·브랜딩 가이드. 검증: 2026-06-08.

## 앱 이름
- 토스 앱에 노출되는 이름 — 서비스 성격이 바로 이해되게.
- 특별한 이유 없으면 한글로 작성 (예: `토스` O / `Toss` X).
- 영문명이 필요하면 15자 이내, 발음하기 쉬운 명사형.

## appName (앱 ID)
- 앱 스킴 호출 기준 ID. **한 번 등록하면 수정 불가** — 신중히.
- `apps-in-toss.config.ts`의 `appName`과 일치시킨다 (SDK 2.x 프로젝트는 `granite.config.ts`).

## 부제
- 사용자가 어떤 서비스를 쓸 수 있는지 한눈에 이해되도록 간결하게.
- **비속어·느낌표(!) 사용 금지.**
- 디자인 컨셉의 카피 보이스를 유지하되 과장 표현("최고"·"유일") 금지.

## 상세 설명
- 사용자가 서비스에서 경험할 수 있는 내용을 **최대한 많이, 구체적으로**.
- 사용자 관점으로 — 핵심 기능·사용 시나리오·차별점 서술.
- 금지: 과장 표현, 금융상품 추천성 문구, 외부 서비스·앱 설치 유도.

## 카테고리
- 실제 선택 가능한 카테고리 목록은 `references/categories.md` 참조 (콘솔 실데이터). **선택 가능(`isSelectable`) 항목만** 추천한다 — 금융 그룹은 파트너 선택 불가.
- 대분류에 소분류가 있으면 **대분류 + 소분류** 조합으로 표기 (예: "콘텐츠 · 운세").
- SUBMIT.md에는 PLAN.md 주제·타겟 기반으로 **카테고리 2개**(추천 1순위 + 대안 1개)를 제안한다.

## 고객센터 정보
- 이메일·연락처·채팅 상담 주소. 미입력 시 등록 보류될 수 있음.

## 에셋 규격 (ait-assets 산출물과 일치)
| 에셋 | 규격 |
|---|---|
| 앱 로고 | 600×600 PNG, **배경색 필수**(투명 배경 불가) |
| 썸네일 | 1932×828 PNG |
| 스크린샷 | 세로형 636×1048 (최소 3장) 또는 가로형 1504×741 (최소 1장) — 본 파이프라인은 세로형 3장 |

## 검수자용 출시 노트 (스토어 노출과 별개)
- 콘솔 "빠른 검토를 위해, 앱의 주요 화면과 기능을 간단히 소개해주세요" 입력란.
- 검수자 관점 — 앱 전체를 처음 보는 사람에게 주요 화면·기능 소개, 3~6줄.
