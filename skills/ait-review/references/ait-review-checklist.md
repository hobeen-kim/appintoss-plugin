# 검수 체크리스트

> 21개 앱 실제 반려 사례 기반. 출시 전 아래 11단계를 순서대로 실행한다.

## 1단계: granite.config.ts 검증

- [ ] `appName` 설정됨
- [ ] `brand.displayName` 설정됨 — **Developer Center 콘솔에 등록한 앱 이름과 반드시 일치 (띄어쓰기 포함 완전 동일)**
- [ ] `brand.primaryColor` 설정됨 (예: `'#3182F6'`)
- [ ] `brand.icon` 설정됨 (600x600px 권장) — **콘솔에 업로드한 아이콘 URL과 반드시 일치**
- [ ] `permissions` 배열 존재 (빈 배열이라도 필수)
- [ ] `web.port` 설정됨
- [ ] `web.commands.dev` / `web.commands.build` 설정됨
- [ ] `defineConfig` import가 `@apps-in-toss/web-framework/config`에서 옴

## 2단계: package.json 검증

- [ ] `@apps-in-toss/web-framework` 의존성 존재
- [ ] `@toss/tds-mobile` 의존성 존재
- [ ] `@toss/tds-mobile-ait` 의존성 존재

## 3단계: TDS Provider 분기 검증

App.tsx (또는 최상위 컴포넌트)에서:
- [ ] AIT 환경 감지 로직 존재 (`navigator.userAgent`, `__GRANITE__`)
- [ ] `TDSMobileAITProvider` (AIT 환경) 사용
- [ ] `TDSMobileProvider` (브라우저 환경) 사용, `colorPreference: 'light'`

## 4단계: UI/UX 검증

- [ ] TDS 컴포넌트만 사용 (커스텀 HTML/CSS UI 요소 금지)
- [ ] 라이트 모드만 지원
- [ ] adaptive 색상 토큰 사용 (다크모드 자동 대응)
- [ ] 제스처 확대/축소 비활성화
- [ ] 진입 시 바텀시트 자동 열림 없음
- [ ] 인터랙션 반응 2초 이내
- [ ] **커스텀 뒤로가기 버튼/네비게이션 바 없음** — AIT 공통 내비게이션 바가 뒤로가기를 제공하므로 페이지 내에 별도 뒤로가기 구현 금지. 토스 내비게이션 바의 뒤로가기와 자체 구현 버튼이 동시에 노출되면 반려됨
- [ ] 모든 버튼이 TDS `Button` / `IconButton` / `TextButton` 사용
- [ ] 모든 입력이 TDS `TextField` / `TextArea` / `SearchField` 사용
- [ ] 모든 리스트가 TDS `ListRow` / `GridList` 사용
- [ ] **닫기 버튼 정상 노출·동작** (게임: 우측 상단) — 모든 화면에서 미니앱을 나갈 수 있는 방법이 명확해야 함 (공홈)
- [ ] **최초 화면에서 뒤로가기 선택 시 미니앱 종료** (공홈)
- [ ] **OS(운영체제) 뒤로가기 제스처에 의존하지 않음** — 사용 불가 (공홈)
- [ ] **Safe Area 및 iOS Dynamic Island 영역 침범 금지** (공홈)
- [ ] 특정 화면 전환 시 바텀시트로 사용자 행동 강제 유도하지 않음 (공홈)
- [ ] CTA 버튼만 보고도 다음 행동을 예측할 수 있음 (공홈)
- [ ] **다크패턴 디자인 없음** — 고객 예상을 벗어난 설계 시 출시 불가 (공홈)
- [ ] 문구에 비속어/은어/과도한 유행어 미포함 (공홈)
- [ ] 사용자 안내가 필요하면 TDS 모달 사용 (공홈)
- [ ] (사운드 사용 시) 무음 모드/시스템 진동 꺼짐에도 의도한 동작 유지, 사용자가 직접 On/Off 설정 가능 (공홈)
- [ ] (사운드 사용 시) 백그라운드 전환 시 사운드 즉시 종료, 복귀 시 정상 재생 (공홈)
- [ ] 탭바 사용 시 토스 앱과 동일한 플로팅 형태로 구현 (공홈)

## 5단계: 콘텐츠 정책 검증

- [ ] 자사 앱 설치 유도하지 않음 (문구, 배너, 앱마켓 링크)
- [ ] 주요 기능이 외부 링크에 의존하지 않음
- [ ] 금융상품 추천/중개/판매/광고 하지 않음
- [ ] 외부 링크는 법률 고지, 공공기관 등 단순 정보 확인용만 허용
- [ ] 사행성/복권/베팅/도박성 요소 없음 (공홈)
- [ ] 투자 자문/종목 추천/투자 전략 안내 없음 (공홈)
- [ ] **디지털 자산/가상자산(NFT 포함) 소유·거래·발행 기능 없음** (공홈)
- [ ] **자금세탁 위험 — 현금·자산의 직접 교환·전환·환불 기능 없음** (공홈)
- [ ] 불법 행위 조장(신분 조작, 해킹, 불법 문서 제공 등) 없음 (공홈)
- [ ] **의료 — 원격진료/병원 예약/순위/광고비 수취 구조 없음** (공공데이터 기반 단순 정보 조회만 가능) (공홈)
- [ ] (쇼핑몰) 고객센터·환불정책 제공 (공홈)
- [ ] (교육) 국가 전문자격증 보유 (공홈)
- [ ] 불법성/선정성 등 위법 콘텐츠 미포함 (공홈)

## 6단계: AI 생성 콘텐츠 (해당 시)

- [ ] AI 활용 사실 사전 고지 (최초 이용 시)
- [ ] AI 생성 결과물에 라벨/배지/워터마크 표시
- [ ] `dangerouslySetInnerHTML` 미사용

## 7단계: 광고 정책 (광고 사용 시)

- [ ] 테스트 ID → **운영 ID로 교체 완료**
- [ ] `isSupported()` 체크 후 광고 API 호출
- [ ] cleanup 함수 호출하여 리소스 정리
- [ ] "광고" 표기 제거/변조하지 않음
- [ ] SDK 기본 클릭/노출 로직 수정하지 않음
- [ ] 자동 클릭/자동 새로고침 등 비정상 트래픽 없음
- [ ] 광고 색상, 배치, 크기 임의 변경하지 않음
- [ ] 클릭 시 리워드 제공 문구 추가하지 않음
- [ ] 핵심 플로우(결제/가입/로그인) 중 광고 노출 없음
- [ ] 광고 빈도 제한/쿨다운 적용 (과도한 노출 방지)
- [ ] 보상형 광고: `userEarnedReward` 이벤트에서만 보상 지급
- [ ] 보상형 광고: 중복 보상 방지 로직 구현
- [ ] 보상형 광고: 끝까지 시청 시에만 보상 정상 지급 (공홈)
- [ ] 광고 종료 시 미니앱 화면으로 정상 복귀
- [ ] 광고 재생 중 배경음/효과음 일시 정지 및 복귀 후 재개
- [ ] 네트워크 실패 시 재시도/대체 흐름 존재
- [ ] **인앱 광고는 인트로/로딩/컷신/팝업 모달 등 일시적 화면에 노출되지 않음** (공홈)
- [ ] 사용자가 예상하기 어려운 순간에 광고 미노출 (공홈)
- [ ] 광고는 사전 로딩, 실시간 로딩 미시행 (공홈)
- [ ] **배너 광고는 상단/중앙/하단 등 적절한 위치, 스크롤 가능한 화면에만 노출** (공홈)
- [ ] 앱인토스 전면형/보상형/배너 광고만 사용 (공홈)

- [ ] 불필요한 리렌더링 없음
- [ ] 이미지/에셋 최적화

## 10단계: 어뷰징 방지

- [ ] 동일 워크스페이스에 유사 기능 앱 없음
- [ ] 테마/대상만 다른 반복 앱 아님

## 11단계: 콘솔 설정 확인

- [ ] 앱 로고 등록 (600x600px 정사각형)
- [ ] **앱 이름이 granite.config.ts의 `displayName`과 일치 (띄어쓰기 포함 완전 동일해야 함 — "나의 금융 계산기" ≠ "나의금융계산기")**
- [ ] **영문 기능명이 디폴트 값이 아닌 실제 이름으로 설정됨**
- [ ] **아이콘이 granite.config.ts의 `brand.icon`과 동일한 이미지**
- [ ] 카테고리 선택 완료
- [ ] 기본형 상세페이지 / 부제(20자) / 상세 설명 작성
- [ ] 검색 키워드 등록

## 접근성 (권장)

- [ ] 텍스트 스케일링 대응 (iOS 접근성 설정)
- [ ] 충분한 터치 타겟 크기 (44px 이상)

## 보안 (서버 있는 프로젝트 필수)

- [ ] **토스 요청 검증** — 모든 `/api` 요청에 `secret` 헤더 검증 미들웨어 적용 (헬스체크 제외)
- [ ] **SECRET_KEY** — `.env`에 설정되어 있고 코드에 하드코딩되지 않음
- [ ] 민감 정보 하드코딩 없음
- [ ] 사용자 입력 검증
- [ ] **외부에서 전달받은 코드 실행 금지** (예: `eval`) (공홈)
- [ ] **브라우저 히스토리 조작으로 자사 사이트 이동하는 방식 금지** (공홈)
- [ ] **SSR(서버 사이드 렌더링) 미사용** — CSR/SSG만 허용 (공홈)
- [ ] **WebSocket 사용 시 암호화된 `wss://` 연결만 사용** (Firebase, Supabase 등) (공홈)
- [ ] 비정상적인 네트워크·메모리 사용량 급증 없음 (공홈)

## 로그인·결제 정책 (해당 시, 공홈)

- [ ] **로그인은 토스 로그인만 허용** — 자사/기타 로그인 방식 미제공
- [ ] 토스 로그인 사용 시 인트로 페이지에서 서비스 설명 제공
- [ ] 설정한 토스 로그인 약관 화면 URL이 정상 노출
- [ ] 로그인 요청 화면에서 닫기 선택 시 미니앱 종료
- [ ] 토스 앱에서 로그인 연결 끊은 뒤 재접속 시 다시 로그인 요청
- [ ] 로그인 연결 끊으면 사용자 데이터가 미니앱에 남지 않음
- [ ] **결제: 실물은 토스페이, 디지털 상품은 인앱결제(IAP)만 허용** — 다른 결제 수단 미제공
- [ ] 결제 진행 시 재생 중인 음악 일시 정지
- [ ] 주문 금액과 결제창 표시 금액 일치
- [ ] 결제 실패 시 사용자가 실패 사유 인지 가능
- [ ] 결제창 취소 시 주문 화면으로 복귀
- [ ] 기기 변경 시 기존 인앱결제 데이터(이용권 등) 유지

## 반려 시 대응

반려 사유는 보통 위 11단계 중 하나에 해당한다. 반려 메시지를 읽고 해당 단계를 수정한 후 재제출한다. 반려 사유는 콘솔 우측 하단 채팅의 상담원 연결로 문의할 수 있다. 검토 요청은 영업일 기준 최대 3일 소요된다. (공홈)

## 최신 반려 사례·정책 (공홈 보강)

- **콘텐츠 제한 8종 (출시 불가)**: 디지털/가상자산(NFT 포함), 자금세탁 위험(현금·자산 직접 교환·전환·환불), 불법 행위 조장, 사행성, 금융상품 중개·판매·광고, 투자 자문, 의료(원격진료/예약/광고비 수취), 기타 내부 정책 위반
- **확인 필요 카테고리**: 의료(공공데이터 기반 정보 조회만), 쇼핑몰(고객센터·환불정책 필수), 교육(국가 전문자격증 필수)
- **생성형 AI**: AI 활용 사실 사전 고지 + 결과물에 명확한 표시(배지·워터마크). 위반 시 최대 3,000만원 과태료
- **어뷰징**: 동일 워크스페이스 유사 핵심 기능 앱 중복 출시 금지, 동일 브랜드로 여러 미니앱 출시 금지(목적·기능이 명확히 다르면 가능). 위반 시 수정 요청 → 미노출 → 등록·운영 제한
- **자사 앱 설치/외부 링크**: 모든 설치 권유·강요 금지, 결제창·다운로드 페이지 이동 금지(법률 고지·공공기관 연결만 허용)
- **다크패턴**: 고객 예상을 벗어난 설계의 미니앱은 출시 불가
